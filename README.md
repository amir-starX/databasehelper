# DatabaseHelper

پلاگین کمکی برای ساده‌سازی کار با دیتابیس در فریم‌ورک.

---

## 📖 معرفی

**DatabaseHelper** یک لایه‌ی نازک و سبک روی `PDO` است که به شما اجازه می‌دهد بدون نوشتن SQL خام،
با دیتابیس کار کنید. این پلاگین سه هدف اصلی دارد:

1. **Schema Builder** — ساخت، تغییر و حذف جدول با کد PHP (به سبک Laravel).
2. **Query Builder** — درج، خواندن، به‌روزرسانی و حذف رکوردها به‌صورت زنجیره‌ای (Fluent).
3. **View Syntax** — سینتکس‌های اختصاصی داخل تمپلیت‌ها (مثل `@db_table`, `@db_count`).

این پلاگین کاملاً روی `Core\Plugin` سوار می‌شود، از hookهای فریم‌ورک استفاده می‌کند و
سینتکس‌هایش را با `TemplateEngine::extend` ثبت می‌کند.

### ویژگی‌ها

- ✅ اتصال خودکار به `PDO` (اول از `$app->db`، بعد از فایل کانفیگ).
- ✅ جلوگیری از SQL Injection با Prepared Statements.
- ✅ پشتیبانی از `CREATE`, `ALTER`, `DROP` و `HAS TABLE`.
- ✅ Query Builder زنجیره‌ای: `where`, `whereIn`, `orderBy`, `limit`, `offset`.
- ✅ متدهای `get`, `first`, `count`, `insert`, `update`, `delete`.
- ✅ کوئری خام با `DB::raw()`.
- ✅ چهار سینتکس آماده برای Viewها.
- ✅ ایزوله‌سازی خطا: خطاها در `error_log` ثبت می‌شوند و برنامه کرش نمی‌کند.
